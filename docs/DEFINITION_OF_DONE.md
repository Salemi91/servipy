# Definition of Done

Una tarea solo se considera terminada cuando:

- [ ] Cumple sus criterios de aceptación.
- [ ] Compila y ejecuta localmente.
- [ ] Tiene pruebas mínimas proporcionales al riesgo.
- [ ] No rompe pruebas existentes.
- [ ] No contiene secretos ni credenciales.
- [ ] Respeta los steering files.
- [ ] No modifica contratos ajenos sin acuerdo.
- [ ] Incluye manejo de errores y validaciones.
- [ ] Fue revisada por otra persona.
- [ ] El Pull Request está aprobado.
- [ ] Está integrada en `main`.
- [ ] La documentación fue actualizada cuando corresponde.
- [ ] Funciona en el entorno desplegado cuando afecta la demo.

## Definition of Ready

Una tarea está lista para comenzar cuando:

- [ ] Tiene objetivo claro.
- [ ] Tiene criterios de aceptación.
- [ ] Se conoce el perfil de usuario afectado.
- [ ] Se conocen dependencias.
- [ ] Existe contrato API cuando involucra frontend y backend.
- [ ] No excede aproximadamente un día de trabajo.
