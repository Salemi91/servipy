# Producto — ServiPy

## Visión
Aplicación web responsive que conecta clientes con profesionales de servicios (plomería, electricidad, limpieza, etc.).

## Roles del sistema
- **CLIENT**: busca y solicita servicios.
- **PROFESSIONAL**: ofrece servicios, gestiona solicitudes.
- **ADMIN**: modera usuarios y contenido.

## Principios MVP (hackathon)
- Priorizar funcionalidad completa sobre perfección visual.
- Solo implementar features definidas en specs aprobadas.
- Cada feature debe ser desplegable de forma independiente.
- Simplicidad: la solución más directa es la preferida.

## Reglas
- No se implementa ninguna funcionalidad que no esté en una spec aprobada.
- No se agregan dependencias innecesarias.
- El producto debe ser demostrable en cada iteración.
